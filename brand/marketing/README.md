## Content Guidelines

### Writing Style
- Clear and professional
- Avoid jargon (or explain when necessary)
- Focus on benefits, not just features
- Use UK English spelling and grammar
- Include specific examples and data
- End with clear calls-to-action

### SEO Keywords
- Fraud risk assessment UK
- GovS-013 compliance
- ECCTA 2023 requirements
- Failure to prevent fraud
- Corporate fraud prevention
- UK fraud regulations
- Fraud risk management software
- Economic crime compliance

### Brand Voice Attributes
- Authoritative but approachable
- Educational and helpful
- Professional and trustworthy
- Clear and transparent
- Solution-oriented

## Asset Management

### Naming Conventions
```
[type]-[topic]-[date]-[version].[ext]
Example: case-study-financial-services-2026-01-v1.pdf
```

### Version Control
- Use version numbers (v1, v2, etc.)
- Include date in filename
- Archive old versions in `/archive` subfolder
- Document changes in version notes

## Review Process

1. **Draft** - Initial content creation
2. **Review** - Compliance and brand review
3. **Approval** - Final sign-off
4. **Publish** - Distribution to channels
5. **Monitor** - Track performance metrics
6. **Optimize** - Iterate based on data
