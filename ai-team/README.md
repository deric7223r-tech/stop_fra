Context documents for AI agents:
- Architecture decisions

- Compliance requirements

## AI Agent Collaboration Guidelines

### When Working on Tasks

1. **Always read existing code** before making changes
2. **Use TodoWrite tool** to track tasks and progress
3. **Follow TypeScript strict mode** - no implicit any
4. **Write tests** for new features
5. **Update documentation** when making changes
6. **Commit frequently** with clear messages

### Agent Specializations

- **Backend Architect:** API design, database schema, security
- **Frontend Engineer:** UI components, user experience, mobile optimization
- **QA Testing:** Test generation, integration testing, security testing
- **Documentation:** Technical docs, user guides, API documentation
- **Marketing Content:** Brand messaging, product descriptions, case studies

### Communication Protocol

- Document all architectural decisions
- Share context with other agents via knowledge base
- Report blockers and issues clearly
- Provide detailed commit messages
- Update task status in real-time

## Quick Start

1. Review `/knowledge-base` for project context
2. Check `/prompts` for task-specific templates
3. Follow `/workflows` for standard procedures
4. Document learnings and patterns for future agents
