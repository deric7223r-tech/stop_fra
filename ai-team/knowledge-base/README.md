## Using the Knowledge Base

### For New AI Agents
1. Read `../CLAUDE.md` for complete project overview
2. Review relevant architecture knowledge
3. Understand compliance requirements
4. Study domain-specific knowledge
5. Learn development standards

- Reference knowledge articles when making decisions
