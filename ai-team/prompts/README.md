# AI Prompt Templates

This directory contains reusable prompt templates for AI agents working on Stop FRA.

## Available Prompts

### Development Prompts
- `feature-development.md` - Template for implementing new features
- `bug-fix.md` - Template for debugging and fixing issues
- `refactoring.md` - Template for code refactoring tasks
- `api-endpoint.md` - Template for creating new API endpoints

### Testing Prompts
- `unit-test.md` - Template for writing unit tests
- `integration-test.md` - Template for integration testing
- `security-test.md` - Template for security testing
- `performance-test.md` - Template for performance testing

### Documentation Prompts
- `api-docs.md` - Template for API documentation
- `user-guide.md` - Template for user documentation
- `technical-spec.md` - Template for technical specifications
- `architecture-decision.md` - Template for ADR (Architecture Decision Records)

### Marketing Prompts
- `product-description.md` - Template for product descriptions
- `case-study.md` - Template for case studies
- `blog-post.md` - Template for technical blog posts
- `social-media.md` - Template for social media content

## Usage

1. Copy the relevant prompt template
2. Fill in the specific details for your task
3. Execute the prompt with the AI agent
4. Document results and learnings

## Creating New Prompts

When creating new prompt templates:
- Be specific and detailed
- Include context about the project
- Specify expected output format
- Include examples where helpful
- Reference relevant documentation
