## Workflow Best Practices

1. **Always follow the workflow steps sequentially**
2. **Document deviations and reasons**
3. **Update workflows based on learnings**
4. **Use TodoWrite to track workflow progress**
5. **Review and validate at each checkpoint**

## Creating New Workflows

When creating workflow documents:
- Define clear entry and exit criteria
- Break down into discrete, actionable steps
- Include validation checkpoints
- Specify required tools and resources
- Add troubleshooting guidance
- Include rollback procedures where applicable
